# R281 — first-pass home-only initramfs build

Date: 2026-10-01

## Result

The R281 home-only build reached image creation successfully, then stopped in the archive-byte verification helper.

This is **not evidence that the archive contains wrong module/firmware bytes**.

Both failed archive hashes were:

```text
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```

which is SHA256 of an empty stream. Therefore the first-pass verification command failed to select the intended cpio members.

## Failure classification

The first-pass verification attempted to select archive members using hard-coded `./usr/...` cpio member names.

The returned empty-stream SHA256 for both module and firmware strongly indicates a member-name selection mismatch rather than archive byte corruption.

R281 therefore remains:

```text
HOME_IMAGE_BUILD=PROVEN
SIGNED_MODULE_BUILD=PROVEN
DEPMOD=PASS
ARCHIVE_MEMBER_BYTE_IDENTITY=UNPROVEN_FIRST_PASS
LIVE=UNPROVEN
```

A second-pass audit should list actual cpio member names, extract exactly those names into a temporary directory, and compare hashes without rebuilding the image.
